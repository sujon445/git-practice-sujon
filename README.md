## Project Overview

A simple Python calculator project created to practice Git and GitHub.

## Features

- Display name and current date
- Add two numbers
- Subtract two numbers
- Multiply two numbers

## Technologies
- Python
- Git
- GitHub

## Testing

The calculator was tested successfully with the inputs `10` and `5`.

Expected results:
- Addition: 15
- Subtraction: 5
- Multiplication: 50
